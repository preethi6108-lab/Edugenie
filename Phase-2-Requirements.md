# Phase 2 - Requirement Analysis

## Functional Requirements
1. Accept student questions and topics.
2. Provide AI-generated answers.
3. Explain concepts in simple language.
4. Generate quizzes.
5. Summarize educational text.
6. Provide learning recommendations.

## Software Requirements
- Python 3.10+
- FastAPI
- Google Gemini API
- Uvicorn
- Jinja2
- HTML, CSS and JavaScript

## Hardware Requirements
- Smartphone or computer
- Internet connection
- Web browser
